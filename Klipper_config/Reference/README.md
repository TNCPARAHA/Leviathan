## 🔧 Printer Specs

**Board**: Leviathan V1.3  
**Printer**: Voron 2.4  
**Toolhead**: Nitehawk Jabberwocky (NHK)  
**Probe**: Cartographer 3D Scanner  
**Bed Size**: 350x350mm  

## 📝 Quick Start

1. Review `pin_mappings.md` for board connections
2. Follow `calibration_guide.md` for initial setup
3. Check component-specific notes for detailed settings
4. Update notes as you tune and calibrate
